# Customer-Churn-Analysis-Prediction
Project Title:
Customer Churn Analysis & Prediction – Identify why customers leave and predict churn to improve retention.

Objective:

Analyze customer behavior and churn patterns.

Build predictive models to identify high-risk customers.

Provide actionable business insights to reduce churn.

Dataset:

Synthetic dataset shaped like Kaggle’s Telco Customer Churn dataset (7043 rows, 21+ features).

Includes demographics, account info, subscription, services, and charges.

Cleaned version available for modeling.

Key Features:

gender, SeniorCitizen, Partner, Dependents

tenure, PhoneService, InternetService

Contract, PaymentMethod, MonthlyCharges, TotalCharges

Derived features like tenure_bucket and encoded categorical variables.

Tech Stack:

Python: pandas, numpy, scikit-learn, matplotlib, seaborn

Modeling: Logistic Regression, Random Forest, SHAP explanations

Reporting: Jupyter Notebook & Executive Summary PDF
